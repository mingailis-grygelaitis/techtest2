# Task board UI exercise

Playwright and TypeScript tests for the [TodoMVC demo](https://demo.playwright.dev/todomvc/). Requires Node.js 22+, npm and internet access. No credentials needed.

```sh
npm run setup
npm test
```

Use `npm run test:headed` to watch the browser, or `npm run typecheck` to check TypeScript.

During the interview, we'll run through the tests together, discuss your observations, and look for inefficiencies and opportunities to improve them.

This is open book and AI-friendly. Identify concerns yourself, and be ready to explain any changes you make.
